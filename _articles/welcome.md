## Adding a new article

To publish a new article:

1. Add a new Markdown file inside the `_articles` folder.
2. Give it a short front matter block at the top, like this:

```
---
title: "Your Article Title"
date: 2026-08-20
---
```

3. Write the article content below that block, using normal Markdown (headings, paragraphs, links, lists, images, etc.).
4. Commit and push — GitHub Pages rebuilds automatically, and the new article appears on the Articles list, with its own clean URL like `/articles/your-article-title/`.

That's it — no need to touch any other file for a normal article.
